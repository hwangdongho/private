개인정보처리방침

시행일: 2026년 11월 13일

상상개발자 채널 도구(이하 "도구")는 유튜브 채널 운영자가 본인 채널을 관리하려고 직접 쓰는 개인용 프로그램입니다. 일반 사용자에게 제공하는 서비스가 아닙니다.

이용하는 정보

도구는 Google OAuth로 운영자 본인 계정에 로그인한 뒤 YouTube Data API와 YouTube Analytics API를 통해 다음만 이용합니다.

  • 운영자 본인 채널의 정보와 통계(조회수, 시청 시간, 유입 경로 등)
  • 운영자 본인이 만든 영상의 업로드와 예약에 필요한 정보

다른 사람의 개인정보는 모으지 않습니다.

보관과 공유

로그인 토큰과 통계는 운영자 본인의 컴퓨터와 본인 소유 저장 장치에만 보관합니다. 제3자에게 팔거나 넘기지 않고, 광고에 쓰지 않습니다.

Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

접근 철회

언제든 Google 계정의 서드파티 앱 접근 설정에서 이 도구의 접근을 끊을 수 있습니다.

문의

문의는 Google Cloud 앱 정보에 등록된 지원 이메일로 받습니다.

Privacy policy (English)

This tool is a personal program used only by the owner of the YouTube channels to manage their own channels. It signs in to the owner's Google account with OAuth and uses the YouTube Data API and YouTube Analytics API only to read the owner's own channel analytics and to upload and schedule the owner's own videos. It does not collect anyone else's data. Tokens and data are stored only on the owner's own computer and storage device, and are never sold, shared with third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from Google Account third-party access settings.
